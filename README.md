# 🎮 MCC 控制面板

一个为 [Minecraft Console Client](https://github.com/MCCTeam/Minecraft-Console-Client) 做的 Web 控制面板。
**不用懂服务器，浏览器打开就能操作 MCC。**

## ✨ 功能

- 🖱️ **网页按钮一键发指令**
- 💬 **实时日志**
- 👥 **在线玩家列表**
- 🔌 **服务器信息面板**
- ⚙️ **连接 / 账号 / 机器人 三标签配置**
- 🤖 **机器人开关**：自动重连、关键词回复、防 AFK、聊天记录
- 💾 **配置自动保存**
- 🔄 **崩溃自动重启**
- 📱 **移动端适配**
